# Memory Keeper

`Memory Keeper` — учебное веб-приложение для хранения и организации личных и совместных воспоминаний с системой контроля доступа.

Проект выполнен на `React + TypeScript` и использует `Firebase` для аутентификации и хранения данных.

## Что реализовано

### Аутентификация
- регистрация пользователя;
- вход по `username + пароль`;
- восстановление пароля;
- защищённые маршруты для авторизованных пользователей.

### Профиль
- редактирование `username`;
- загрузка и удаление аватарки;
- описание профиля;
- настройки конфиденциальности:
  - кому видно описание;
  - кому видна аватарка;
  - кто может открывать совместный доступ;
- смена пароля;
- удаление аккаунта.

### Воспоминания
- создание, просмотр, редактирование и удаление воспоминаний;
- заголовок, текст, дата события, необязательное время;
- место события;
- категории, включая несколько категорий у одного воспоминания;
- теги эмоций, мест и пользовательские теги;
- загрузка нескольких фотографий;
- отдельная страница полного просмотра;
- возврат назад в исходный экран после просмотра и редактирования.

### Организация воспоминаний
- создание, переименование и удаление категорий;
- сортировка:
  - по дате создания;
  - по дате события;
  - по алфавиту;
- фильтрация:
  - по категории;
  - по тегу;
  - по месту;
  - по диапазону дат;
  - по типу доступа;
  - по участнику shared-воспоминания.

### Доступ и совместная работа
- типы доступа:
  - `private`;
  - `public`;
  - `shared`;
- уровни прав:
  - `view`;
  - `comment`;
  - `edit`;
- открытие доступа друзьям;
- отзыв доступа;
- комментарии в совместных воспоминаниях.

### Поиск
- поиск по воспоминаниям:
  - по заголовку;
  - по тексту;
  - по тегам;
  - по участникам;
- поиск пользователей по `username` и `email`;
- поиск публичных воспоминаний пользователя по его `username`.

### Друзья
- поиск пользователей;
- отправка заявки в друзья;
- входящие и исходящие заявки;
- принятие, отклонение и отзыв заявки;
- список друзей;
- переход в профиль пользователя из списка друзей и заявок.

### Уведомления и статистика
- уведомления о заявках в друзья;
- уведомления «воспоминание дня»;
- статистика активности:
  - количество воспоминаний;
  - активность по дням недели;
  - активность по месяцам;
  - популярные теги;
  - популярные места;
  - топ соавторов shared-воспоминаний.

## Технологии

- `React 19`
- `TypeScript`
- `Vite`
- `React Router`
- `Firebase Authentication`
- `Cloud Firestore`
- `CSS`

## Структура проекта

- `src/app` — инициализация приложения, роутинг, провайдеры.
- `src/pages` — страницы приложения.
- `src/widgets` — крупные интерфейсные блоки.
- `src/features` — пользовательские сценарии и формы.
- `src/entities` — доменная логика приложения.
- `src/shared` — общие утилиты, Firebase-конфиг, валидация.
- `firestore.rules` — правила доступа Firestore.

## Локальный запуск

1. Установить зависимости:

```bash
npm install
```

2. Создать файл `.env.local` и добавить переменные Firebase:

```bash
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

3. Запустить dev-сервер:

```bash
npm run dev
```

## Ограничения текущей версии

- часть адаптивности ещё доводится вручную и требует дополнительной проверки на мобильных разрешениях;
- ежедневные уведомления о «воспоминании дня» сейчас завязаны на клиентскую логику приложения;
- проект ориентирован на учебную разработку и не оформлен как production-ready сервис.
